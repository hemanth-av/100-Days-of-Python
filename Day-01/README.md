# Day 01 - Band Name Generator

This beginner-friendly command-line program welcomes the user, collects input data via the console, and joins the strings together. It is a classic starter project from beginner coding courses like The Udemy.

## Key Concepts Used

- **`print()` function:** Displays a welcome message and the final result on the screen.
- **`input()` function:** Prompts the user to type in their city and pet name.
- **Variables:** Stores the user's text inputs in memory (`city` and `pet_name`).
- **String Concatenation:** Joins the separate words together with a space to form the final band name.
- **New Line Escape Character (`\n`):** Keeps the user input neatly formatted on a fresh line.
