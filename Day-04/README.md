# Day 04 - Rock Paper Scissors ✊✋✌️

A classic Rock, Paper, Scissors game played against the computer in the terminal, complete with ASCII art visuals.

## Key Concepts Used

- **`random.randint()`:** Generates the computer's random choice.
- **Lists:** Stores the three ASCII art images indexed by `0`, `1`, `2`.
- **`int()` & `input()`:** Captures and converts the user's choice.
- **`if / elif / else`:** Determines win, lose, or tie based on both choices.
- **Input Validation:** Checks that the user enters a valid number (0, 1, or 2).
